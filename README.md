# WebCreator by TechByDave

Freelance site at **webcreator.techbydave.com**: the "Your business. Fully online." package, plans and prices, and a quote form.

## Go live (10 minutes)
1. Create a GitHub repo **techbydave/webcreator** and push these files (`index.html`, `CNAME`).
2. Repo **Settings → Pages → Deploy from a branch → main / (root)**.
3. At your DNS provider for techbydave.com add: **CNAME** `webcreator` → `techbydave.github.io`.
4. Back in **Settings → Pages**, wait for the green DNS check, then tick **Enforce HTTPS**.
5. Optional: add the Cloudflare Web Analytics script before `</body>` (same as techbydave.com) and add the site to Google Search Console.

## Editing
- Prices and plan contents: the `#plans` section of `index.html`.
- The quote form opens the visitor's email app addressed to dave@techbydave.com (no server needed).
- "Recent work" links: the `#work` section.
