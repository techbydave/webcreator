About WebCreator

Hi, I'm Dave. I build websites small businesses can actually run.

WebCreator is the web studio of TechByDave, based in Toronto. I design the site, set up the tools behind it, and hand you one simple dashboard, so you can get back to the work you're good at.

Work with me Visit TechByDave

I started TechByDave to explain technology in plain English. Building it taught me that most small businesses don't need more tech: they need the right few tools, set up properly, and someone who answers when they have a question.

The story

From a tech blog to a web studio.

Where it started

A tech blog called TechByDave

I started TechByDave to write honest reviews of gadgets: is it worth it, or a waste of money? It grew into a consumer tech publication with a newsletter, videos and a growing audience across TikTok, Instagram, YouTube, X and Pinterest.

  • Reviews
  • Newsletter
  • Shorts
Learning by building

I built everything behind it myself

No templates. I wrote the site generator that publishes techbydave.com, automated the publishing schedule, and built a private analytics dashboard that pulls in website, search and social numbers. Every tool I now set up for clients, I use every day.

  • HTML, CSS & JavaScript
  • Python
  • Automation
  • Dashboards

RON Family Agape Counselling Solutions needed more than a new website. I redesigned the site and built a dashboard where she answers email, approves bookings and sees her visits, plus her Google Business Profile and professional email.
